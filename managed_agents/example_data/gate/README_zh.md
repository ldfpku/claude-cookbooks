# Gate：费用审批人

一份 `policy.yaml` 和十二张票据（`inbox/receipts.jsonl`），供 `CMA_gate_human_in_the_loop.py` 使用。智能体用两个自定义工具依据政策对每张票据分类：明确的批准与拒绝用 `decide()`，任何含糊情况用 `escalate()`。

这十二张票据经过设计，覆盖政策的每个分支：少数几张应干净地自动批准，一张在政策要求票据图片处缺少图片，几张落在需经理批准的区间，两张超过阈值，一笔差旅费用无论金额都必须上报，还有一张类别被故意设置得含糊。一次顺利的运行会产生 `approve`、`reject` 和 `escalated` 结论的混合结果，绝不会全部落在同一通道。
