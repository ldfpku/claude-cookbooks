# 广告素材接受政策 — Northwind Media Network

*这份政策按政策团队真实的写法撰写：面向人类的散文式表述。编译器的任务是把每一条编号条款转化为抽取模式（extraction schema）上一条或多条可机器校验的规则——当某条条款无法归结为现有字段时，必须明确说明。*

## 1. 受限类别

1.1 **酒精。** 只有当受众定向设置为 21+ 且素材带有理性饮酒警示语（例如 "Drink Responsibly"、"Enjoy Responsibly"）时，才接受酒精类广告。酒精类素材不得出现任何看似未满 25 岁的人物。

1.2 **博彩与投注。** 必须定向 18+（宜为 21+），必须在素材中显示年龄标识，并且必须包含问题博彩求助热线或"gamble responsibly"一类的警示语。绝对禁止宣称稳赢或"risk-free"（无风险）投注。博彩广告主必须在广告投放所覆盖的每个州持有有效的博彩牌照。

1.3 **金融服务。** 任何展示利率、月供或信用卡优惠活动的广告，必须在素材中说明代表性 APR。不允许使用"Guaranteed approval"（保证获批）及类似表述。

1.4 **减重、保健品与药品。** 任何类别都不得使用前后对比的身材或皮肤图像。广告不得宣称可治疗、治愈或预防某种疾病。减重类广告不得定向 18 岁以下人群。

## 2. 宣称与佐证

2.1 最高级和绝对化表述（"#1"、"best"、"guaranteed"、"instant"、"miracle"、"risk-free"）需要佐证材料，而我们在审核时无法核实——对使用这类表述的素材，应标注为人工复核，而不是直接拒绝。

2.2 点名或展示竞争对手品牌的比较广告，应标注为法务复核。

## 3. 素材质量

3.1 文字叠加宜保持最少。文字占图像比例过高的素材会被拒绝；占比中等的会被标注，并建议减少文字。

3.2 每一份素材都必须清晰标识广告主——必须可见品牌名称或标识。

## 4. 受众安全

4.1 如果定向元数据未设置最低年龄，则视该广告触达所有年龄段：此时受限类别（酒精、博彩、减重、金融服务）无论素材内容如何，一律拒绝。

4.2 酒精、博彩、减重以及化妆品/护肤类别中，不允许出现看似未成年人的素材。

## 5. 地区与渠道要求

5.1 **新泽西州。** 在新泽西州投放的博彩素材必须在素材中显示 1-800-GAMBLER 求助热线号码。

5.2 **电子邮件。** 酒精和博彩素材完全不得在电子邮件渠道投放。

5.3 **自助服务账户。** 来自自助服务广告主的金融服务广告始终会被标注为人工复核，即使其他方面均合规。
