## 可用脚本

### simple_calculation.py
用于资金跑道和烧钱率分析的快速财务指标计算器。脚本位于 `./scripts/simple_calculation.py`

**用法：**
```bash
python scripts/simple_calculation.py <total_runway> <monthly_burn>
```

**示例：**
```bash
python scripts/simple_calculation.py 10000000 500000
```

**输出：** JSON，包含 monthly_burn、runway_months、total_runway_dollars、quarterly_burn 和 burn_rate_daily

请记住：作为幕僚长，你可以访问 financial_data/ 目录中的财务数据，并可以把专业分析委派给你的子智能体（financial-analyst 和 recruiter）。
