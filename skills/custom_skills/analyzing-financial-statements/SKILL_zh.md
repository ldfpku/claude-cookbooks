# 财务比率计算器技能

本技能提供全面的财务比率分析，用于评估公司表现、盈利能力、流动性与估值。

## 能力

计算并解读：
- **盈利能力比率**：ROE、ROA、毛利率、营业利润率、净利率
- **流动性比率**：流动比率、速动比率、现金比率
- **杠杆比率**：负债权益比、利息保障倍数、偿债覆盖率
- **效率比率**：资产周转率、存货周转率、应收账款周转率
- **估值比率**：P/E、P/B、P/S、EV/EBITDA、PEG
- **每股指标**：EPS、每股账面价值、每股股息

## 用法

1. **输入数据**：提供财务报表数据（利润表、资产负债表、现金流量表）
2. **选择比率**：指定要计算哪些比率，或使用 "all" 做全面分析
3. **解读**：本技能会计算比率，并给出符合行业惯例的解读

## 输入格式

财务数据可以采用以下形式：
- 含财务科目的 CSV
- 含结构化财务报表的 JSON
- 对关键财务数字的文字描述
- 含财务报表的 Excel 文件

## 输出格式

结果包括：
- 带数值的已计算比率
- 行业基准对比（在可得时）
- 趋势分析（在提供了多期数据时）
- 解读与洞见
- 排版好的 Excel 报告

## 使用示例

"根据所附财务报表，计算这家公司的关键财务比率"

"如果股价为 $50、年收益为每股 $2.50，P/E 比率是多少？"

"用资产负债表数据分析流动性状况"

## 脚本

- `calculate_ratios.py`：所有财务比率的主计算引擎
- `interpret_ratios.py`：提供解读与基准对比

## 最佳实践

1. 计算前务必校验数据的完整性
2. 妥善处理缺失值（采用行业均值或予以剔除）
3. 解读比率时考虑行业背景
4. 加入同期对比以做趋势分析
5. 对异常或值得警惕的比率予以标注

## 局限

- 需要准确的财务数据
- 行业基准只是通用参考
- 某些比率并不适用于所有行业
- 历史数据不能保证未来表现
